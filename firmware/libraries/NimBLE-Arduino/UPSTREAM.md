# NimBLE-Arduino vendor record

This directory vendors the source needed by the gateway so its LiTime BLE
transport does not depend on a machine-local Arduino library. It is imported
from [h2zero/NimBLE-Arduino](https://github.com/h2zero/NimBLE-Arduino), release
`2.5.1` (`5ae2c43f62c5a588a25c1de68f7d17b6f3b75adb`), under Apache-2.0.

Only the upstream `src/` tree and required licensing/metadata files are
included. Update this record and retain the upstream `LICENSE` and `NOTICE`
when upgrading.
